# Security Policy

## Supported Versions

Only the `main` branch and the latest stable release receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a vulnerability in `everything-imu-mobile` (for example an issue
in the IMU/UDP streaming path, the discovery handshake, or the OSC haptics
listener that could lead to crashes or unauthorized access on the local
network), report it privately using
[GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

All reports are reviewed and addressed as quickly as possible.
